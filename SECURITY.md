# Security policy

## Reporting a vulnerability

Please report security issues privately, never in a public issue.

- Use GitHub's private reporting: the **Security** tab of [XKD-Labs/simpledatalogs-python](https://github.com/XKD-Labs/simpledatalogs-python/security/advisories/new) → "Report a vulnerability".
- Or email **mail@xkdlabs.com**.

Include the SDK version, what you found and how to reproduce it. We aim to answer within 3 working days and to ship a fix for confirmed issues as soon as we can.

## Supported versions

Fixes go into the latest release. Upgrade to it before reporting.
